# 案例层 → 类型层映射文档（CASE_MAPPING）

## 说明

Lean 形式化系统验证的是条件命题：

  "如果某案例满足类型结构中的字段赋值，那么定理结论成立。"

本文档说明每个案例实例（如 `China_case`）的字段赋值依据，
使形式化前提可被审计、可被证伪、可被更新。

本文档不是证据库，而是**字段赋值的证据索引**。
完整证据应存放在案例库或外部文献中，本文档只给出指向和判定摘要。

---

## 来源权重定义

| 权重 | 含义 | 可接受证据类型 |
|---|---|---|
| A | 直接证据 | 官方记录、司法文书、可核实的媒体报道、当事人陈述 |
| B | 间接/结构性证据 | 制度分析、统计数据、政策文件、学术研究 |
| C | 推断/假设 | 基于 A/B 的合理推断，或暂缺证据的临时赋值 |

规则：
- 字段赋值至少需一条 A 或 B 级证据；
- C 级证据必须显式标记，并在 SORRY/CALIBRATE 中登记；
- 同一字段有多条证据时，以最低权重作为该字段的当前置信等级。

---

## 映射规则

每个字段赋值必须满足：

1. **证据指向操作化定义**，而不只是结论。
   - 可接受："2015 年女权五姐妹被拘"指向 `was_erased := true` 的"主动清除"定义。
   - 不可接受："中国女性组织不存在"直接指向 `org_exists := false`，无操作化标准。

2. **反例被排除或标注**。
   - 若存在"组织仍在运作"的反例，需说明为何不计入（如规模阈值、独立性标准）。

3. **版本化**。
   - 字段赋值变更必须标注日期和依据变更原因。

## 当前案例映射

### `China_case`（Chain 6 / `OrganizationPrerequisite`）

| 字段 | 赋值 | 依据摘要 | 来源权重 | 日期 |
|---|---|---|---|---|
| `org_exists := false` | 中国不存在独立运作的女性组织网络 | 1995 年北京世妇会后独立女性组织被系统性压制；现存组织多为行政附属或注册困难 | B | 2026-07-07 |
| `was_erased := false` | 无被清除的独立组织——**从未形成** | 框架作者裁定（2026-07-19）：原锚定不成立——女权五姐妹系行动者网络非组织；高校社团系学校行政管辖物，均未达 Independent(O) 阈值。中国 feminist org 域 erased 为空集；妇联为 state-built 占位主体（pre-occupied，通道功能近零），从建制起位置即被预占 | A（作者裁定） | 2026-07-19 |

**2026-07-19 改挂记录**：`was_erased := true → false`（Formation_Erased → Formation_Absent / pre-occupied）。Lean 实例 `China_case` 已同步改值，定理更名 `China_is_absent_not_erased`（编译验证待 Claude 节点 lake build）。

**F9 中国真案例**（与组织轨道无关）：计划经济单位制托育 = 行政配置的 F9_partial（非权利性制度），市场化转型中成本外部化被收回——"赠予型 F9_partial 可撤回性"锚点，证明方向：无独立组织托底的 F9 赠予物撤回时无防御主体在场。分析见案例文档《F9失效分析_中国vs北欧》（当前存草稿区，待入库）。

**话语层归类裁定**（2026-07-19，框架作者）：针对女性言论空间的系统性清除（炸群/炸号/举报关闭，如豆瓣大型女性群组被关）归 **A7**（强制基础设施——通道消除），不归 A5-负向执行（承认层过滤）。判据：女性言论存在不进入男性承认经济，其消除不是承认操作而是通道阻断。

反例审查：
- 存在小型线上女权社群和海外组织；
- 排除理由：`OrganizationPrerequisite` 中的 `org_exists` 操作化定义要求"可形成制度性制衡的独立组织网络"，线上社群未达到该阈值。

## 维护规则

1. 每次向 Lean 添加新的案例实例，必须同步更新本文档。
2. 形式化编译不依赖本文档，但审计和升 HARDENED 时必须检查本文档。
3. 字段赋值与本文档不一致时，以 Lean 代码为准，但必须登记 `[CALIBRATE-CASE-MAPPING]`。
