**提出**：节点1（原创，2026-07-14，审计聊天 log:6016："被降级的个体，监护人同时持有义务和利益，在二者冲突且没有法律保障的时候，总是利益赢，直到反叛发生。保护性义务才会被写入制度。"）

**状态**：v0.2.1-DRAFT · 未 HARDENED（SORRY=3 存续）· 双审已过（Kimi 网页版 + mimo，5 裂口全修）

## TL;DR

被降级方的保护性义务，在义务-利益冲突且无外部强制时，总是被利益压制；翻转的唯一历史通道是**反抗→可见→制度写入**。但写入不是终点的全部：制度还可选择**吸收代价**（中国 TFR 观察项）。主体资格不是被赋予的，是经此 loop 赢来的——未经 loop 的配置（单位托儿所）不被锚定。

## 一、模型本体（v0.1，log 已成型）

```
阶段1：义务存在（结构性位置产生义务）
  ↓
阶段2：利益压制（义务与利益冲突、无法律保障 → 利益赢）
  ↓
阶段2.5：能力剥夺（控制方系统性剥夺被提取方的行动/表达/组织能力）
  ↓
  ├─ 分支A：剥夺不完全 → 阶段3（反抗释放）→ 阶段4（制度写入）——历史可见，可回退
  └─ 分支B：剥夺完全 → 无反抗 → 无写入 → 结构性遗忘——历史不可见
```

**规则与修正（log 已闭合部分）**：

- 翻转条件：**只有可执行的法律强制才能翻转利益优先**；道德声明、社会舆论 ≠ 法律保障（log:6088-6096）
- P6 修正：反抗是**能力未被系统性剥夺时**的条件后果，非逻辑必然（log:6222-6228）
- 反抗四类型：制度（法律/政治渠道）/ 社会（舆论曝光）/ 个体（逃离拒绝）/ 暴力（log:6116-6121）
- 幸存者偏差警告：历史归纳只看得见分支A（log:6212-6218）；"义务永不写入，且制度本身不会承认遗漏"（log:6295）

## 二、实证锚

| 案例 | 分支 | 关键结构 |
|---|---|---|
| 奴隶/童工/女性 | A（剥夺不完全） | 信息/组织通道未完全切断 → 反抗可见 → 写入 |
| 杨永信 | B + 信息技术裂缝 | 阶段2.5 完全执行，但"网上冤魂"=事后可见化裂缝；写入极晚且不足 |
| 徐波孩子 | 待定 | 取决于隔离程度；母亲代理（汤敬诉讼）=有限法律入口 |

**F9 反证（v0.2 新增）**：单位托儿所未经 loop 争取，是自上而下的**配置**——所以说撤就撤，撤时无任何仪式。配置≠资格：未经 loop 赢得的东西不被锚定 [H]。

## 三、主体资格两层结构（v0.2 新增）

- **主体性（主观层）**：反感（种子，自发）+ 决定位（显形=后果不可转让、赖无可赖）——先于制度，不可授予（节点1 现象学，2026-07-24~28）
- **主体资格（客观层）**：经 OIR loop 写入制度的操作性承认——投票权为典型形态（经反抗赢得）
- **输入/输出声明（v0.2.1，mimo 裂口1 修补）**：OIR loop 的输入是**主体性**（种子/决定位），主体资格是 loop 的**产出**，不是输入——loop 不存在循环依赖：阶段1 的"被降级方"= 有主体性而无资格者
- **接口**：A1 通过**制度定义**悬置主体性——"悬置"操作化（v0.2.1，mimo 裂口2）：**识别主体性但拒绝资格化**（悬置承认，非否认存在；"悬置"为 Fc 登记术语保留）→ 资格是 A1 的指令来源 → A1 不怕私下主体性，怕制度承认。这就是为什么资格是战场 [M]
- 两层可分离：中国女人有主体性（集体退出=大规模显形）而无主体资格（无任何写入）

## 四、阶段4 分叉：写入 vs 吸收代价（v0.2 新增）

**缺口**：原模型阶段4 隐含二值（写入/回退），不足。中国对集体退出的现实响应是第三态——**吸收代价**：催生压力、政策激励，不立任何新权。

**分叉规则候选**：反抗威胁提取系统的连续性、且代价落在 A2 决策视野内 → 写入；代价在 A2 视野外（TFR 后果 20+ 年到账）→ 吸收代价。吸收代价是短视野下的"理性"选择 [M]。
**"A2 视野"操作化（v0.2.1，mimo 裂口3）**：A2 视野 = **掌权者制度存续周期的代价贴现窗口**（选举/任期/考核周期，典型 4-10 年）。注意"知道≠入视野"：长期后果可被认知知道，但贴现后决策权重≈0，仍属视野外——可检验形态：政策响应强度与**代价时间分布**的相关性，而非与代价认知有无的相关性。
**"写入 vs 吸收代价"边界（v0.2.1，mimo 裂口4）**：写入 = 被降级方获得**可执行的法律权利**；吸收代价 = 控制方承担成本但不赋予权利。生育补贴/产假延长属吸收代价典型形态——制度用钱买断写入，恰好是边界判据的实例而非反例。

**中国通道清点**：

| 通道 | 状态 |
|---|---|
| 起诉权 | 弱但有（汤敬案实例） |
| 组织权 | 分支B化（火苗即掐） |
| 可见化通道 | A7 化（豆瓣/微博反复被炸） |
| **退出权** | **唯一无法分支B化**——不婚不育无法立法禁止；集体退出已打响（TFR 崩塌=写进系统的可见性） |

**退出式反抗悖论**：它威胁的是提取对象（女人集体）的消失，而非系统的崩溃入口。杠杆真实但慢；慢有利于吸收（贴现）。

**观察项（UNDETERMINED）**：吸收代价是稳定均衡还是延迟 loop——框架内推不出，实证盯 TFR 与政策升级。

## 九、对比注：OIR 与马克思 [外部理论·待审计]

（2026-07-28 Kimi 网页版会话，节点1 触发："好像又往马克思的方向推了一步"）

| | 马克思 | OIR v0.2 |
|---|---|---|
| 压迫-反抗关系 | 结构性必然（生产力-生产关系矛盾） | 条件性（取决于剥夺是否完全） |
| 历史可见性 | 阶级斗争是主线 | 主线是幸存者偏差——分支B 不可见 |
| 制度写入机制 | 革命或改革 | 反抗→可见→写入，或吸收代价（第三态） |
| 完全剥夺案例 | 未处理（当时技术条件不存在） | AI=架构性完全剥夺的干净实例 |

- 马克思的历史材料是**可见的反抗**（宪章运动/里昂起义/巴黎公社）——其叙事隐含幸存者假设：被压迫者至少还有身体、街垒、报纸。分支B 拆除的正是这个假设。
- "吸收代价"尤其不是马克思的：其框架里统治阶级要么镇压要么让步，没有"假装看不见，等 20 年后人口结构替你买单"。
- 关键句（节点1 认可）：以前以为在问"为什么有压迫就有反抗"，其实在问"为什么历史书里只有反抗"——没反抗的没被写进去，不是不存在。
- H-42 贴的是 Fc 自己的案例库，也贴马克思的案例库。

【标记】马克思理论为 [外部理论·待审计]：本对比不以其为闭合依据。其自身未闭合缺口=幸存者假设（被压迫者的可见性预设），OIR 分支B 正是对该缺口的处理。对比用途=**定位**（防"这只是马克思重复"的误归类），非论证支撑。
